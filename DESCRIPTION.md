# YouTube description

Generated by `scripts/make_description.py` from the same drill JSON that drives the video,
so the two cannot disagree. **Never hand-write one.** If a line reads badly, fix the JSON
and the video picks up the same change.

```
python3 scripts/make_description.py src/drills/<id>.json --out out/descriptions
```

## The shape

```
<problem.pain>                      ← the hook

<title>｜<subtitle>

主題：…｜類別：…
人數：…｜難度：…｜年齡：…
場地：…｜時間：…

【練習目標】   problem.aim
【開始】       start positions, and who serves
【點樣分勝負】 winning.home / winning.away / winning.decides
【輪轉】       rotation.note
【重點】       points, numbered
【變化】       variations
【進階】       progression

<question>

#足球訓練 #足球戰術 #粵語 #青訓 #教練
```

A block with no content is skipped entirely rather than printed empty.

## The first two lines are the whole pitch

YouTube truncates to roughly **150 characters** in search results and channel previews, so
everything above the fold is the hook and the title. The hook is `problem.pain` — the thing
that goes wrong in a match — because a coach recognises their own team in it before they
know what the drill is.

## 【開始】 earns its place

The video shows the start cones and the serve; the description has to say them too, or a
coach reading before watching cannot set the drill up. It is drawn from the `start` zones
and the `ballStart` actor, both of which come from the session plan.

## Tone

Same split as the video: the structure labels are standard written Chinese, the sentences
are colloquial spoken Cantonese, because they are quoting the narration. **球員, never
波仔.**

## Channel description

Separate from the per-video one, at `out/descriptions/channel.txt`. It says only what the
videos are about — no audience list, no upload cadence, no hashtags. Anything promising a
schedule has to be confirmed with the person before it goes up, because nothing here can
keep that promise.
